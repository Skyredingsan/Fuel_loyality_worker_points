## 🎯 О проекте

**Топливный Альянс** — это программа лояльности для территориальных менеджеров, которая превращает выполнение KPI в увлекательный процесс с уровнями, баллами и привилегиями.

**Цель:** Повысить эффективность работы территориальных менеджеров через материальное и нематериальное стимулирование.

**Девиз:** *«Твоя территория — твоя империя. Развивай и получай заслуженные привилегии»*

## ✨ Функциональность

### Для Территориального Менеджера (ТМ)
- 📊 Просмотр своих результатов по KPI
- 🎯 Отслеживание прогресса по категориям:
    - Продажи и маржа
    - Операционная эффективность
    - Эффективность команды
    - Культура безопасности
- 🏆 Получение уровней и привилегий
- 📎 Просмотр подтверждающих документов

### Для Эксперта
- ✏️ Ввод результатов по ТМ
- 📎 Загрузка подтверждающих документов
- 📋 Редактирование черновиков

### Для Координатора
- 👥 Управление пользователями
- 🎯 Настройка KPI показателей
- 📊 Просмотр отчетов
- ✓ Подтверждение результатов
- ✗ Отклонение с указанием причины
- 📥 Экспорт данных в CSV

## 🚀 Установка и запуск

### Предварительные требования
- Go 1.21 или выше
- Node.js 18 или выше
- npm или yarn

### Бэкенд

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/fuel-points.git
cd fuel-points

# Установить зависимости
go mod download

# Создать базу данных
go run scripts/init_db.go

# Заполнить тестовыми данными
go run scripts/seed_data.go
go run scripts/seed_kpi_data.go

# Запустить сервер
go run cmd/api/main.go
Сервер будет доступен по адресу: http://localhost:8080
```

### Фронтенд

```bash
# Перейти в папку фронтенда
cd frontend

# Установить зависимости
npm install

# Создать .env файл
echo "VITE_API_URL=http://localhost:8080/api" > .env

# Запустить в режиме разработки
npm run dev
```
